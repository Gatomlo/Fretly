# Fretly

App web (PWA) pour guitariste, pensée smartphone et tablette : accordeur, carnet de chant avec accords, bible des accords, lecteur mains libres.

```
npm install && npm start   # http://localhost:8080 ; déployé via node-gateway (apps/fretly)
npm test
```

Voir [CLAUDE.md](CLAUDE.md) pour l'architecture.
